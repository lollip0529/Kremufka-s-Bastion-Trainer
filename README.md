# Kremufka-s-Bastion-Trainer
Map for training bastion routes and movement for speedrunners

## Sharing routes

A shared route is one small `.nbt` file. Cheats have to be on (or Open to LAN with cheats) to use the structure block.

**Export:** open Saved Routes, click **[Export]** next to a route, right-click the structure block, type a file name and press SAVE, then click **[Done]**. The file is in your world folder under `generated/minecraft/structures/<name>.nbt`.

**Import:** put the file in the same folder of your own world, open Saved Routes, click **[Import]**, right-click the structure block, type the file name and press LOAD. The map rebuilds the route's bastion and adds it to your routes. Importing the same route again updates it instead of adding a copy.

The file carries the bastion's seed and settings rather than its blocks, so routes saved before sharing existed need their layout rebuilt in the editor before they can be exported.
